SUHS Gateway

Make .suhs and .root addresses work in your browser. Install the extension and SUHS registry addresses just work — no settings to change, no VPN, nothing running in the background.

Every SUHS registry user gets a free site at <name>.sendushomesafe.com and an editor at <name>.sendushomesafe.com/root. This extension lets you reach them by their short names instead:

You typeIt opens
<name>.suhshttps://<name>.sendushomesafe.com — the public site
<name>.roothttps://<name>.sendushomesafe.com/root — the editor

Paths and query strings carry over (muse-test.suhs/about?page=2 works), and it handles https:// too — the redirect happens before the browser ever tries to resolve the name, so there is no certificate error. Try it after installing: muse-test.suhs · muse-test.root

Install — Chromium (Chrome, Edge, Brave, Opera, Vivaldi, Arc)

All six browsers run the same package and install it the same way. There is no one-click install yet: the extension is not in any store, so you load it yourself in Developer Mode.

  1. Download suhs-extension-chromium.zip above and extract it to a folder. Keep that folder — the browser reads the extension from it.
  2. Open your browser's extensions page:
    BrowserExtensions page
    Google Chromechrome://extensions
    Microsoft Edgeedge://extensions
    Bravebrave://extensions
    Opera / Opera GXopera://extensions
    Vivaldivivaldi://extensions
    Arcchrome://extensions
  3. Turn on Developer mode (the toggle, usually top-right; in Edge it is in the left sidebar).
  4. Click Load unpacked and select the extracted folder (the one containing manifest.json).
  5. Pin the SUHS Gateway icon in the toolbar if you want it visible. Type muse-test.suhs in the address bar to check it works.
Honest note: Chrome shows a warning every time it starts while Developer Mode extensions are loaded. That goes away only with a store listing — the Chrome Web Store charges a one-time $5 developer registration, and Edge and Opera have their own add-on stores. A store listing is the path to one-click install later; for now, Developer Mode is the way.

Install — Firefox (desktop)

Firefox still supports temporary installs of unsigned extensions, but they are removed when the browser closes. A permanent install needs a Mozilla-signed .xpi, and this build is unsigned — signing it (free, through addons.mozilla.org) is the next step before a permanent install is possible.

  1. Download suhs-extension-firefox.zip above and extract it to a folder.
  2. Open about:debugging#/runtime/this-firefox in the address bar.
  3. Click Load Temporary Add-on… and select manifest.json inside the extracted folder.
  4. It works immediately. It will be gone after you restart Firefox — repeat these steps, or wait for the signed build.

The .xpi file above is the same package in Firefox's install format. It is provided for signing and submission, not for installing as-is: Firefox will refuse an unsigned .xpi for a permanent install.

Install — Tor Browser

Tor Browser is built on Firefox, so the Firefox package above is the one to use, installed the same temporary way (about:debugging → Load Temporary Add-on → select manifest.json). It is removed when Tor Browser closes.

Read this first — the Tor Project's own advice is not to do this. The Tor Project recommends running Tor Browser with no additional add-ons: any extra extension makes your browser more distinguishable from a stock Tor Browser, which can weaken your anonymity. The SUHS Gateway extension itself sends nothing anywhere new — it only rewrites .suhs / .root addresses to their real sendushomesafe.com pages, which are then fetched over Tor like anything else — but the extension's presence is detectable. Only install it in Tor Browser if you accept that trade-off. If anonymity is the point of the session, use the ordinary Firefox or Chromium install instead.

Apple devices — use Orion (free)

There is no Safari package, because Apple charges $99 a year to distribute one — and there doesn't need to be. Orion is a free browser for Mac, iPhone, and iPad that installs Chrome and Firefox extensions directly, so the SUHS Gateway extension works in it the same way it works everywhere else. No Apple developer account, no App Store listing, nothing paid to Apple.

  1. Get Orion from Kagi — Mac download from their site, iPhone and iPad from the App Store link on that page.
  2. Install the SUHS Gateway extension in Orion like any Chrome or Firefox extension. One-click install from the Chrome Web Store or Firefox Add-ons is the next step (the extension isn't listed in any store yet); until then, load the Chromium or Firefox package above in Orion's extension manager.
  3. Type muse-test.suhs to check it works.
Honest note: Orion's extension support is still partial — Kagi puts it at roughly 70% of the extension APIs — and this extension has not been tested in Orion yet. It only uses simple redirect rules, so it should work, but "should" is not "tested." If it doesn't fire in Orion, try the other package (Chromium vs Firefox).

Other free routes on a Mac: install Firefox or Chrome and use the extension there — Apple has nothing to do with it. In Safari itself, a Mac user can build the Safari version with free Xcode and a free Apple ID and run it via Develop → Allow Unsigned Extensions, but each user has to build it themselves and the setting resets when Safari restarts. On iPhone, SideStore can sideload a Safari build with a free Apple ID (certificates expire every 7 days and refresh automatically). A one-click Safari install for other people is the only thing that needs the $99 a year.

Privacy

The extension only redirects navigation to .suhs and .root addresses. It collects no data, tracks nothing, reads no page content, and changes no settings. Its only permissions are the .suhs / .root addresses themselves and the redirect mechanism.
